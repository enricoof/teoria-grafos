Guia interativo de Teoria dos Grafos — navegue pelos tópicos

O que é um grafo?

Pensa no Instagram. Cada pessoa é um vértice (nó). A conexão entre duas pessoas é uma aresta (arco). Isso é um grafo.

nós = pessoas arestas = conexões

Dígrafo (direcionado)

A seta tem sentido. Você segue a Anitta, ela não te segue de volta.

par ordenado seta indica sentido

Grafo simples

Sem laço (seguir a si mesmo) e sem aresta duplicada entre dois nós.

sem laços sem paralelas

Grafo completo (Kₙ)

Todo mundo conectado com todo mundo. K₄ = 4 nós, todos se conhecem.

Grafo bipartido (Km,n)

2 grupos. Só conecta entre grupos, nunca dentro do mesmo.

Fórmula de Euler para grafos planares

Para grafos planares, conexos e simples, vale sempre:

n − a + r = 2

n = nós a = arestas r = regiões

Kuratowski: se o grafo contém K₅ ou K₃,₃, ele é não planar

Como o computador guarda um grafo?

Existem duas formas principais. A escolha depende de quantas arestas o grafo tem.

Matriz de adjacência

Tabela n × n. Cada célula diz se tem aresta entre linha e coluna.

Ideal para grafos DENSOS

Lista de adjacência

Cada nó tem uma listinha de quem ele se conecta.

Ideal para grafos ESPARSOS

Como lembrar?

Denso = muitas arestas → matriz (todo mundo fala com todo mundo, a tabela é cheia)
Esparso = poucas arestas → lista (economiza espaço, só guarda quem realmente se conecta)

O que é uma árvore?

Um grafo conexo e sem ciclos (sem volta). Tem sempre uma raiz no topo. Uma árvore com n vértices tem exatamente n − 1 arestas.

Caminho Euleriano

Passa por cada aresta exatamente 1 vez.

Analogia: o carteiro quer passar em cada rua sem repetir nenhuma.

Quando existe?
Se tiver 0 ou 2 nós com grau ímpar (número ímpar de conexões).

Caminho Hamiltoniano

Passa por cada vértice exatamente 1 vez.

Analogia: o vendedor quer visitar cada cidade uma só vez.

Dificuldade:
NP-completo — computador não resolve rápido para grafos grandes.

Macete para a prova

Euler = aRESTas   Hamilton = vérTICEs

Grau do nó = quantas arestas chegam nele. Se for número ímpar, o nó tem grau ímpar.

BFS — Busca em Largura

Explora nível por nível. Visita todos os vizinhos antes de ir mais fundo.

Usa FILA (primeiro a entrar, primeiro a sair).

DFS — Busca em Profundidade

Vai fundo num ramo até o fim, depois volta e tenta outro.

Usa PILHA (último a entrar, primeiro a sair).

Macete infalível

BFS → Largura → FLa → FILa    DFS → Profundidade → PILha

Ordenação topológica — usada em DAGs (grafos direcionados sem ciclo). Organiza nós respeitando as setas. Ex: ordem de matérias com pré-requisitos.

Árvore geradora mínima (AGM)

Conecta todos os nós com o menor custo total. Pensa em ligar cidades com o menor km de estrada possível.

Prim

Começa num nó. Vai sempre adicionando a aresta mais barata que conecta um nó novo.

Grafos densos Usa fila de prioridade.

Kruskal

Ordena todas as arestas do menor para o maior peso. Vai adicionando desde que não forme ciclo.

Grafos esparsos Usa union-find.

Caminhos mínimos

Dijkstra

1 origem → todos. Só funciona com pesos positivos. Usa fila de prioridade.

Bellman-Ford

1 origem → todos. Aceita pesos negativos. Detecta ciclo negativo.

Floyd-Warshall

Todos os pares de uma vez. Complexidade O(n³).

Macete de prova:
Dijkstra = pesos ≥ 0
Bellman = negativos ok
Floyd = todos os pares

Fluxo máximo

Imagina um sistema de canos. Cada aresta tem uma capacidade máxima de água. Quanto consegue passar da fonte até o destino?

Algoritmo de Ford-Fulkerson resolve isso.

Teorema do corte mínimo: o fluxo máximo que passa pela rede é sempre igual ao corte mínimo (o "gargalo" da rede).

Problema das 4 cores

Qualquer mapa planar pode ser colorido com no máximo 4 cores, de forma que países vizinhos nunca tenham a mesma cor.

Aplicações: cartografia, escalonamento, processamento de imagens.
